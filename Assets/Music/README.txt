Положи сюда музыкальные треки (.mp3, .ogg, .wav, .flac, .xm, .mod, .it, .s3m).

Можно также положить их прямо в Assets/ — плеер сканирует обе папки.
Файлы копируются в output автоматически при сборке (см. LogicSim.Game.csproj).

Управление:
  F7  — громкость -
  F8  — громкость +
  F9  — play/pause
  F10 — следующий трек (Shift+F10 — предыдущий)
