# LogicSim

Визуальный редактор и симулятор логических схем на C# + [Raylib-cs](https://github.com/raylib-cs/raylib-cs).

![LogicSim screenshot](docs/screenshot.png)

## Что это

LogicSim — редактор, в котором можно собирать цифровые схемы из логических вентилей, соединять их проводами, наблюдать распространение сигнала в реальном времени и сворачивать подсхемы в переиспользуемые макросы.

Проект в активной разработке.

## Возможности

### Логика

- **4-значная логика сигнала**: `0`, `1`, `Z` (High-Z, нет драйвера), `X` (короткое замыкание — несколько драйверов с разными уровнями).
- **Элементы**: `IN`, `OUT`, `NAND`.
- **Макросы** (`ChipElement`): любую выделенную подсхему можно свернуть в блок и использовать как обычный элемент. Внутри — обычная схема, клонируется при постановке.
- **Библиотека макросов**: макросы можно откреплять из палитры в отдельную библиотеку, редактировать, возвращать обратно, удалять.
- **`View` / `Open` / `Edit`**:
  - `View` — посмотреть содержимое макроса (read-only).
  - `Open` — редактировать определение макроса; изменения применяются ко всем его инстансам в текущей схеме.
  - `Edit` (в библиотеке) — переименовать, сменить цвета, размер, положение пинов.

### Редактор

- **Главное меню** с созданием новой схемы, загрузкой сохранений, ссылкой на GitHub и выходом.
- **Меню паузы** (по `Esc` в редакторе): продолжить, сохранить или выйти в главное меню.
- Панорама и зум камеры (колесо мыши зумит к курсору).
- Выделение мышью: одиночное, аддитивное (Shift+ЛКМ), рамкой.
- Перетаскивание группы выделенных элементов с запретом пересечения блоков.
- **Провода с waypoints**: клик по пустому месту добавляет точку излома, клик по входу завершает провод.
- **Автоматический запрет waypoint рядом с пином** — чтобы точки не сливались с соединениями.
- **`Ctrl+C` / `Ctrl+V`** — копирование и вставка выделения с hologram-превью.
- **Сетка 20×20 px** и «линейка» в диалоге макроса для контроля реального размера.
- **Индикация состояний**:
  - `0` — красный,
  - `1` — зелёный,
  - `Z` — серый пунктир,
  - `X` (короткое замыкание) — чёрно-красная «сигнальная лента».
- Подсказка состояния провода при наведении.

### Настройка внешнего вида

- Индивидуальные **цвета тел** и **проводов** для каждого элемента.
- 8 предустановленных цветов + **ColorPicker** (Hue/Saturation/Brightness).
- 9-й «recent» цвет в быстром меню пина.
- **Цвет конкретного пина** отдельно от цвета провода.
- Изменение **размера макроса** (Width / Height в диалоге редактирования).
- Произвольная **Y-координата пинов** макроса (перетаскивание пина по боку блока).

### Сохранение

- Схема и библиотека макросов сохраняются в **JSON** (`%APPDATA%/LogicSim/Saves`).
- Формат версионирован, структура самодостаточна — рекурсивно включает содержимое макросов.
- **Удаление сохранений** прямо из диалога загрузки.
- **Быстрое сохранение** (`Ctrl+S` или через меню паузы) в текущий файл без запроса имени.

## 🎓 Обучение (С чего начать)

Если вы запустили LogicSim впервые, вот пошаговый гайд, как собрать свою первую схему.

### Шаг 1. Создание схемы
При запуске вас встречает **Главное меню**. Нажмите **New Circuit**, чтобы начать с чистого листа. (Если у вас уже есть сохранения, вы можете загрузить их кнопкой **Load Circuit**).

### Шаг 2. Добавление элементов
Внизу экрана находится панель инструментов. Нажмите на кнопку **IN** (вход), затем кликните в любом месте на бесконечном рабочем поле.
Появится зелёный блок — это ваш переключатель. Кликните по его пину (кружочку слева), чтобы переключить значение с `0` на `1`.
Добавьте ещё один **IN** и один **NAND** (логическое И-НЕ).

### Шаг 3. Соединение проводами
1. Нажмите левой кнопкой мыши на **выходной пин** (справа) первого блока `IN`. Начнёт тянуться провод.
2. Кликните по пустому месту — добавится точка излома (waypoint), чтобы провод не пересекал другие элементы.
3. Наведите на **входной пин** (слева) элемента `NAND` и кликните. Провод зафиксируется.
4. Повторите то же самое для второго `IN`.

### Шаг 4. Просмотр результата
Добавьте элемент **OUT** и соедините выход `NAND` с его входом.
Теперь кликайте по пинам ваших `IN` блоков. Вы увидите, как по проводам бежит сигнал:
- **Зелёный цвет** — логическая `1`.
- **Тёмно-красный/тусклый** — логический `0`.
- Если замкнуть два разных сигнала на один вход, провод станет чёрно-красным (короткое замыкание).

### Шаг 5. Создание макроса (Чипа)
Соберите, например, `XOR` из нескольких `NAND`. Затем:
1. Зажмите `Shift` и выделите все элементы рамкой (или просто кликайте по ним с зажатым `Shift`).
2. Внизу нажмите зелёную кнопку **MAKE MACRO**.
3. Введите название (например, `XOR`) и выберите цвет. Кнопка Create станет активной.
4. Нажмите **Create**. Ваша схема свернётся в один аккуратный блок, который теперь можно штамповать бесконечно!

### Шаг 6. Пауза и сохранение
Нажмите **Esc** на клавиатуре. Откроется меню паузы.
- **Continue** — вернуться к редактированию.
- **Save** — если вы сохраняете впервые, откроется диалог с именем файла (без пробелов и спецсимволов). В дальнейшем кнопка Save будет перезаписывать текущий файл.
- **Exit to Main Menu** — вернуться в главное меню (не забудьте сохраниться!).
