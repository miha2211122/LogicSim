# LogicSim

Визуальный редактор и симулятор логических схем на C# + [Raylib-cs](https://github.com/raylib-cs/raylib-cs).

![LogicSim screenshot](docs/screenshot.png)

## Что это

LogicSim — редактор, в котором можно собирать цифровые схемы из логических вентилей, соединять их проводами, наблюдать распространение сигнала в реальном времени и сворачивать подсхемы в переиспользуемые макросы.

Проект в активной разработке.

## Возможности

### Логика

- **4-значная логика сигнала**: `0`, `1`, `Z` (High-Z, нет драйвера), `X` (короткое замыкание — несколько драйверов с разными уровнями).
- **Элементы**: `IN`, `OUT`, `NAND`.
- **Макросы** (`ChipElement`): любую выделенную подсхему можно свернуть в блок и использовать как обычный элемент. Внутри — обычная схема, клонируется при постановке.
- **Библиотека макросов**: макросы можно откреплять из палитры в отдельную библиотеку, редактировать, возвращать обратно, удалять.
- **`View` / `Open` / `Edit`**:
  - `View` — посмотреть содержимое макроса (read-only).
  - `Open` — редактировать определение макроса; изменения применяются ко всем его инстансам в текущей схеме.
  - `Edit` (в библиотеке) — переименовать, сменить цвета, размер, положение пинов.

### Редактор

- Панорама и зум камеры (колесо мыши зумит к курсору).
- Выделение мышью: одиночное, аддитивное (Shift+ЛКМ), рамкой.
- Перетаскивание группы выделенных элементов с запретом пересечения блоков.
- **Провода с waypoints**: клик по пустому месту добавляет точку излома, клик по входу завершает провод.
- **Автоматический запрет waypoint рядом с пином** — чтобы точки не сливались с соединениями.
- **`Ctrl+C` / `Ctrl+V`** — копирование и вставка выделения с hologram-превью.
- **Сетка 20×20 px** и «линейка» в диалоге макроса для контроля реального размера.
- **Индикация состояний**:
  - `0` — красный,
  - `1` — зелёный,
  - `Z` — серый пунктир,
  - `X` (короткое замыкание) — чёрно-красная «сигнальная лента».
- Подсказка состояния провода при наведении.

### Настройка внешнего вида

- Индивидуальные **цвета тел** и **проводов** для каждого элемента.
- 8 предустановленных цветов + **ColorPicker** (Hue/Saturation/Brightness).
- 9-й «recent» цвет в быстром меню пина.
- **Цвет конкретного пина** отдельно от цвета провода.
- Изменение **размера макроса** (Width / Height в диалоге редактирования).
- Произвольная **Y-координата пинов** макроса (перетаскивание пина по боку блока).

### Сохранение

- Схема и библиотека макросов сохраняются в **JSON** (`%APPDATA%/LogicSim/Saves`).
- Формат версионирован, структура самодостаточна — рекурсивно включает содержимое макросов.
