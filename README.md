# LogicSim

Гайд по управлению и возможностям (v1.0.0).

## Запуск

Проект на **C# / .NET 8** + **raylib-cs**.

```bash
dotnet run --project LogicSim.Game.csproj
```

Сохранения — `*.json` в `%APPDATA%\LogicSim\Saves` (папка создаётся автоматически).

Музыка — положи треки в `Assets/Music/` (или прямо в `Assets/`): `.mp3`, `.ogg`, `.wav`, `.flac`, `.xm`, `.mod`, `.it`, `.s3m`. Управление: `F7`/`F8` — громкость, `F9` — play/pause, `F10` — следующий трек (`Shift+F10` — предыдущий).

---

## Главное меню

- **New Circuit** — новый пустой проект.
- **Load Circuit** — список сохранений; файл выбирается кликом, кнопка `x` удаляет его, `Load` открывает.
- **Tutorial / GitHub** — открывает https://github.com/miha2211122/LogicSim.
- **Exit** — выход.

## Элементы

| Клавиша / кнопка | Элемент | Особенность |
|---|---|---|
| `1` / `IN` | Вход | 1–32 бит; левый клик по пину переключает 0/1 |
| `2` / `OUT` | Выход | 1–32 бит; имеет скрытые выходные пины |
| `3` / `NAND` | NAND | 2 входа, 1 выход |
| `4`–`7` / LIBRARY → PARTS | MERGE / SPLIT / CLK / DELAY | Перемещены в библиотеку, хоткеи сохранены |
| LIBRARY → PARTS | `3-STATE` | D проходит при E=1, выход Z при E=0 |
| LIBRARY → PARTS | `PULL UP` / `PULL DOWN` | Слабая подтяжка к 1 / 0; сильный драйвер перекрывает её без `X` |
| `CHIP` | Макрос | Создаётся через `Ctrl+M` / `MAKE MACRO` |

На панели инструментов остались только `IN`, `OUT`, `NAND`. Все остальные примитивы лежат в библиотеке: `LIBRARY` / `Ctrl+L` → вкладка `PARTS` → `Place` → клик по полотну. Вкладка `MACROS` — пользовательские макросы.

Повторное нажатие цифры или повторный клик по кнопке увеличивает счётчик размещения (`x2`, `x3`, …). `0` сбрасывает выбранный инструмент.

Состояния пинов: `0`, `1`, `Z` (High-Z), `X` (Conflict — мигает красным). Многобитные провода рисуются лентой: каждая полоска показывает бит. Ширина подключения должна совпадать (иначе соединение отклоняется). Вход `IN` — кнопка, к ней нельзя подвести провод; уже подключённый вход переключать нельзя.

## Работа в редакторе

### Мышь

- **ЛКМ по элементу** — выделить и перетащить (перетаскивание блокируется при пересечении с другими элементами).
- **ЛКМ по пустому месту** — снять выделение и начать панораму; **MMB** — панорама в любом месте.
- **Shift + ЛКМ** — добавить/убрать элемент из выделения; если не по элементу — прямоугольное выделение (с Shift — аддитивное).
- **ЛКМ по выходному пину → клики-точки изгиба → ЛКМ по входному пину** — проложить провод. `Esc` / `РКМ` отменяет.
- **Наведение на провод** — всплывает состояние сети (`0`, `1`, `Z`, `SHORT (X)`).
- **РКМ по пину / элементу / проводу** — контекстное меню.
- Кнопки HUD справа сверху: **Save (Ctrl+S)**, **Load (Ctrl+O)**, при вложенности — **< Back**.

### Клавиатура

| Клавиша | Действие |
|---|---|
| `1`–`7`, `0` | Выбор инструмента / сброс |
| `Space` | Пауза / продолжение симуляционного времени (CLK и DELAY замирают, логика считается дальше) |
| `.` | Один такт вручную (работает на паузе) |
| `T` | Настроить период CLK или задержку DELAY под курсором |
| `Ctrl+S` | Сохранить (если путь уже известен — сразу, иначе диалог Save As) |
| `Ctrl+O` | Открыть список сохранений |
| `Ctrl+Z` | Отмена (история 100 шагов) |
| `Ctrl+Y`, `Ctrl+Shift+Z` | Повтор |
| `Ctrl+C` | Скопировать выделение |
| `Ctrl+V` | Вставить: привидение следует за курсором, клик — поставить, `Esc`/`РКМ` — отмена |
| `Ctrl+D` | Дублировать выделение (дальше как вставка) |
| `Ctrl+A` / `Ctrl+Shift+A` | Выделить всё / снять выделение |
| `Ctrl+M` | Создать макрос из выделения |
| `Ctrl+L` | Библиотека макросов |
| `Delete` | Удалить выделенное или элемент под курсором |
| `F1` | Справка по хоткеям прямо в игре |
| `Home` | Сброс камеры |
| `Колесо` | Масштаб к курсору |
| `+` / `-` | Масштаб к центру экрана |
| `Esc` | Отменить провод/вставку/диалог; в корне — меню паузы; внутри чипа — выход |
| `[` / `]` | Предыдущий / следующий активный слой |
| `V` | Скрыть/показать активный слой |
| `K` | Заблокировать/разблокировать активный слой |
| `G` | Переместить выделение в активный слой |

В диалогах: `Enter` — подтвердить, `Esc` — отмена, `Backspace` — удалить символ. В диалоге макроса `Shift` меняет шаг размера с 10 до 1.

## Контекстные меню

**По элементу (РКМ):** палитра цвета корпуса, `Custom...` (HSV-пикер), для чипов — `View` (только чтение) и `Open` (редактирование), `Bus Width...` (для IN/OUT/MERGE/SPLIT), `Period...` / `Delay...` (для CLK/DELAY), `To Active Layer`.

**По пину (РКМ):** `Rename pin...` (до 14 символов: буквы, цифры, `_`, `-`), `Pin color...`; для выходного пина — готовые цвета провода и `Wire color...`. Цвет выходного пина перекрывает цвет провода элемента; последний нестандартный цвет сохраняется и предлагается в следующий раз.

**По проводу (РКМ):** `Delete wire`, `To Active Layer`.

**По макросу в нижней панели (РКМ):** `Unstar` — убрать из панели в библиотеку.

**HSV-пикер:** три слайдера Hue / Saturation / Value, предпросмотр с HEX-кодом, `OK` / `Cancel`.

## Макросы (чипы)

- `Ctrl+M` или кнопка `MAKE MACRO` — собрать выбранные элементы в чип. Внешние провода автоматически переподключаются к новым пинам.
- Диалог создания/редактирования: имя (до 14 символов), цвет корпуса и провода, размеры `W`/`H`, перетаскивание пинов по сторонам предпросмотра для настройки смещений, цвета пинов и `Reset`.
- `Ctrl+L` / кнопка `LIBRARY`: `Edit` (править прототип), `Attach` (вернуть в панель), `Delete`, `Close`.
- Правка шаблона через библиотеку или `Open` на чипе обновляет **все экземпляры** этого макроса.
- Внутри чипа: `Esc` или `< Back` — выход; режим `VIEW` — только просмотр.

## Слои

Панель слоёв справа сверху: `<` / `>` — выбор активного, `+` — добавить (до 8), строки слоёв — клик по строке выбирает слой, кнопки `V` (видимость) и `K` (блокировка).

- **Скрытые слои** не рисуются и не участвуют в хит-тесте/выделении.
- **Заблокированные слои** защищены от перемещения, удаления, перекраски, переименования пинов, смены разрядности и создания проводов.
- Новые элементы и провода попадают в активный слой; `G` и пункты `To Active Layer` переносят объекты.
- Симуляция **не зависит** от видимости: скрытые цепи продолжают считаться.
- У каждого чипа свой набор слоёв; всё сохраняется в JSON и в undo/redo.

## Файлы и отмена

- Save As: имя до 40 символов (буквы, цифры, `_`, `-`, пробел, `.`), `.json` добавляется автоматически.
- Load: выбор файла, удаление крестиком, папка и список обновляются сразу.
- В меню паузы (`Esc` в корне): `Continue`, `Save`, `Exit to Main Menu`.
- Undo/redo хранят 100 снапшотов, включая слои, цвета, подписи пинов и разрядности.
- Вставка и перемещение блокируются при пересечении с видимыми элементами.
